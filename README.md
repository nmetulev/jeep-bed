# Monster Lifted Jeep Bed — with stealth trundle

A twin bed for a kid, shaped like a lifted Jeep, with a second twin that rolls out
from underneath. Built from four sheet goods and a stack of construction lumber.

**→ [Open the interactive plans](https://metulev.com/jeep-bed/)**

Everything — the 3D model, six scale blueprints, the cut list, the plywood nesting
diagrams and the build guide — is generated from one shared set of dimensions, so
they cannot disagree with each other. Change the paint or the wall setting and the
drawings redraw.

## What's in the page

| Tab | What it gives you |
| --- | --- |
| **3D model** | Orbit it, pull the trundle out, explode it into its parts, toggle layers, repaint it. Seven Jeep colours plus custom pickers. |
| **Blueprints** | Side elevation, front elevation, frame plan, trundle plan, cross-section, and a full-size side-panel cutting pattern. |
| **Cut list** | Every part, grouped by material, with the reasoning in the notes. Includes the knock-down hardware schedule and a shopping list. |
| **Sheet layouts** | How each part nests on a 4×8 sheet. Three sheets against a wall, four free-standing. |
| **Build guide** | Fourteen steps, in order, including how to take it apart again. |

## Design decisions worth knowing

- **Each side is one piece.** The side panel is a single 79 × 48 cut — the full width
  of a 4×8 sheet — with the hood line, raked A-pillar, roof rail, door aperture and
  rear quarter window all in that one cut. No seams, no glue-ups.
- **Nothing crosses the bed at head height.** There is no windshield panel and no
  rear-window panel, because a cross-body part there would sit directly over the
  sleeper. The only members spanning the bed are two 2×4 roof braces, 29 3/4" above
  the mattress.
- **It comes apart.** Threaded inserts and socket-cap bolts, not screws — 37 bolts
  and one hex key. It gets built in the room and it can leave the room.
- **The trundle breathes.** Nose and tail are open and the black rocker band floats
  with a 1" gap top and bottom, so air moves through the bay instead of sitting
  under foam in a closed box.
- **The trundle slats hang inside its rails**, not on top of them, which drops the
  deck 2" and is the only reason an 8" mattress fits under there.

## Running it locally

`index.html` is one self-contained file — Three.js is inlined, there are no other
assets and no network calls. Download it and double-click it.
